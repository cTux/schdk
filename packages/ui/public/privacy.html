SCHDK

Privacy Policy

Effective: July 31, 2026

SCHDK is a web and desktop application for creating, storing, editing, and hosting “What? Where? When?” question packages.

Google user data we access

After you authorize SCHDK, the application reads your Google account display name, email address, and profile image. It uses Google Drive to create and manage SCHDK packages and related files and synchronize private application settings.

SCHDK requests access only to files it creates or that you explicitly open with it, plus its private application-data folder. Shared question rules and dictionaries are bundled with the application and require no access to your Drive. SCHDK does not inspect unrelated Drive files.

How data is used and stored

Game packages, personal question rules, question packages, settings, the rebuildable question index, and any AI API key you choose to save are stored in your own Google Drive. Browser access tokens are held only in memory. The desktop application stores refresh credentials locally using operating-system encryption and does not expose them to its web interface.

SCHDK has no application server that receives your Drive files or OAuth tokens. Data moves directly between your device and Google.

Data protection

SCHDK connects to Google APIs and optional AI providers only over encrypted HTTPS connections. Google Drive files and application data remain protected by the access controls and security of the user's Google Account. SCHDK limits Drive requests to files it creates or that you explicitly open with it and to its private application-data folder.

Browser OAuth access tokens are short-lived, held only in memory, and discarded when the page closes or reloads. Desktop refresh credentials stay outside the web interface and are encrypted with the operating system's protected credential storage. SCHDK does not log OAuth tokens, saved AI API keys, or private Drive file contents.

Optional AI providers

AI-assisted authoring runs only when you request it. SCHDK then sends the question-generation input to the provider you selected—OpenAI, Anthropic, or Google—using your own API key. Personal question-index content is not sent to an AI provider. The selected provider processes submitted data under its own privacy policy.

Sharing, advertising, and human access

SCHDK does not sell Google user data, use it for advertising, or share it except to provide features you explicitly request. No person reads your private data unless you explicitly ask for support involving that data, access is required for security or legal reasons, or you give specific consent.

Retention and deletion

Your Drive files remain in your account until you delete them. You can remove SCHDK files in Google Drive, remove a saved AI key in SCHDK, disconnect the application, or revoke SCHDK access from your Google Account. Revoking access prevents future access but does not delete files already stored in your Drive.

Google API Services User Data Policy

SCHDK’s use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

Contact

For privacy questions or deletion assistance, contact the developer through the SCHDK issue tracker.
