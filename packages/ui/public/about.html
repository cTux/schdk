SCHDK

SCHDK is a web and desktop application for creating, storing, editing, and hosting “What? Where? When?” question packages.

Open SCHDK Privacy Policy

What SCHDK does

Authors can prepare question packages, edit questions and handouts, organize reusable question-creation rules and dictionaries, and host a game from the same application. Optional AI-assisted authoring uses the provider and API key selected by the user.

Why SCHDK requests Google Drive access

SCHDK stores the current user's packages and application data in their Google Drive. It also loads app-specific shared question rules and dictionaries. The application limits its requests to its app-marked SCHDK folder, its private application-data folder, and configured shared SCHDK folders; it does not inspect unrelated Drive files.

Drive data and OAuth tokens move directly between the user's device and Google. SCHDK does not operate an application server that receives those files or tokens. See the Privacy Policy for complete data-use, storage, sharing, retention, and deletion disclosures.
