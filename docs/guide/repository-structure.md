# Структура репозиторію

```text
.
├── docs/
│   ├── GAME_PACKAGE.md      # формат .schdk і правила валідації
│   ├── README.md            # індекс користувацької документації
│   ├── RULES.md             # індекс усіх правил проєкту
│   ├── guide/               # окремі тематичні посібники
│   └── rules/               # правила за архітектурними й продуктовими зонами
├── packages/
│   ├── web/                 # браузерна оболонка, редактор і проведення гри
│   ├── desktop/             # Electron-застосунок
│   ├── common/              # спільна модель пакета та ZIP-кодек
│   ├── google-drive/        # Drive REST і контракт налаштувань
│   └── ui/                  # компоненти, стилі, ресурси та правила UI
├── scripts/                 # перевірки workflow репозиторію
├── package.json             # кореневі команди та версії інструментів
├── pnpm-workspace.yaml      # робочий простір і каталог залежностей
└── turbo.json               # завдання збирання, тестів і перевірок
```
