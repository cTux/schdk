# Вимоги

- Windows для поточної конфігурації пакування Electron.
- Node.js 24.x LTS.
- pnpm 11.x. У репозиторії зафіксовано pnpm 11.7.0.

Перевірити встановлені версії:

```powershell
node --version
pnpm --version
```

Якщо pnpm відсутній, установити потрібну версію:

```powershell
npm install --global pnpm@11.17.0
```
