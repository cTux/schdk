# Вимоги

- Windows або Linux для нативного пакування відповідної Electron-версії.
- Node.js 24.x LTS.
- pnpm 11.x. У репозиторії зафіксовано pnpm 11.18.0.

Перевірити встановлені версії:

```powershell
node --version
pnpm --version
```

Якщо pnpm відсутній, установити потрібну версію:

```powershell
npm install --global pnpm@11.18.0
```
