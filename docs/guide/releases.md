# Релізи та вебверсія

Вебверсія автоматично збирається після кожного оновлення гілки `main` і
публікується за адресою <https://ctux.github.io/schdk/>.

Щоб створити Windows-реліз:

1. Налаштуйте GitHub Secrets `WINDOWS_CERTIFICATE_BASE64` із PFX-сертифікатом у
   base64 та `WINDOWS_CERTIFICATE_PASSWORD` із його паролем.
2. Додайте до `CHANGELOG.md` розділ `## X.Y.Z` з описом змін українською мовою.
3. Запустіть workflow `Release` для гілки `main` і введіть ту саму версію без
   префікса `v`.
4. Дочекайтеся появи GitHub Release `vX.Y.Z`.

До релізу додаються два файли:

- `schdk-X.Y.Z-windows-x64-installer.exe` — інсталятор;
- `schdk-X.Y.Z-windows-x64-portable.exe` — портативна версія без встановлення.

Workflow зупиниться, якщо версія має неправильний формат, відповідний розділ
changelog відсутній, його текст не містить українських літер, секрети
сертифіката відсутні або підпис будь-якого виконуваного файла невалідний.
