# Релізи та вебверсія

Вебверсія автоматично збирається після кожного оновлення гілки `main` і
публікується за адресою <https://ctux.github.io/schdk/>.

Щоб створити реліз, попросіть Codex: `make a release`. Репозиторна
навичка `$schdk-release` автоматично:

1. визначить наступну patch-версію, якщо версію не вказано;
2. підготує український розділ `## X.Y.Z` у `CHANGELOG.md` з окремими списками
   продуктових і технічних рішень та оновить
   `packages/all-web-app/version.json` до тієї самої версії;
3. створить pull request, дочекається обов’язкових перевірок і об’єднає його;
4. запустить workflow `Release` для `main`;
5. дочекається створення інсталятора на Windows;
6. перевірить тег, нотатки й файл GitHub Release.

До одного релізу `vX.Y.Z` додаються:

- `schdk-X.Y.Z-windows-x64-installer.exe`.

Для автоматичного випуску мають бути налаштовані GitHub Actions secrets:

- `GOOGLE_DESKTOP_CREDENTIALS_JSON`.

Workflow зупиняється до публікації, якщо changelog або версія невалідні,
`version.json` не збігається з версією релізу, перевірки не пройшли, бракує
секрету або інсталятор відсутній чи порожній.
Інсталятор публікується без цифрового підпису.

Кожен пункт changelog починається з одного з префіксів `[NEW]`, `[CHANGE]`,
`[FIX]`, `[DELETE]` або `[SECURITY]`.
