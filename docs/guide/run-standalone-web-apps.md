# Окремий запуск вебзастосунків

Для роботи лише з однією частиною проєкту використовуйте такі команди:

| Команда               | Результат                                               |
| --------------------- | ------------------------------------------------------- |
| `pnpm dev:editor-web` | Запускає окремий браузерний редактор через Vite.        |
| `pnpm dev:host-web`   | Запускає окрему браузерну оболонку ведучого через Vite. |

Окремі Vite-команди використовують стандартний механізм вибору порту Vite.
Для перевірки навігації між застосунками краще запускати спільну команду
`pnpm dev`.
