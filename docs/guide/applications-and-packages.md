# Застосунки та пакети

| Пакет робочого простору  | Призначення                                                                                                                 |
| ------------------------ | --------------------------------------------------------------------------------------------------------------------------- |
| `@schdk/all-web-app`     | Браузерна оболонка з навігацією між проведенням гри, редакторами та налаштуваннями. Це стандартна точка входу для розробки. |
| `@schdk/all-desktop-app` | Electron-застосунок із повною вебоболонкою, авторизацією Google Диска та вузьким мостом для явного експорту пакетів.        |
| `@schdk/editor-web-app`  | Спільний редактор Drive-пакетів із перевіреним локальним імпортом, автозбереженням, недавніми файлами й експортом.          |
| `@schdk/host-web-app`    | Браузерний застосунок ведучого з fullscreen-wizard, таймером, звуком і керуванням станами питання.                          |
| `@schdk/common`          | Спільні типи пакетів, валідація, ZIP-серіалізація та розбір файлів.                                                         |
| `@schdk/google-drive`    | Спільний REST-клієнт Google Диска та контракт синхронізації налаштувань.                                                    |
| `@schdk/ui`              | Спільні UI-компоненти, стилі, токени дизайну, графічні ресурси та правила інтерфейсу.                                       |
