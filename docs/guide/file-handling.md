# Робота з пакетами в браузері та на десктопі

Веб- і десктопний застосунки зберігають пакети в Google Диску. Після входу
створені та імпортовані пакети з'являються у видимій папці `SCHDK` поточного
облікового запису.

- Створення пакета одразу створює його файл на Google Диску.
- Вибір або перетягування локального `.schdk` перевіряє файл та імпортує його
  на Google Диск. Початковий локальний шлях не зберігається.
- Зміни автоматично записуються в той самий Drive-файл після однієї секунди
  без нових правок.
- Недавні пакети завантажуються з Google Диска поточного облікового запису.
- Перезавантаження сторінки або повторний запуск десктопного застосунку
  відновлює останній Drive-пакет і вибране питання, якщо пакет ще доступний.
- Кнопка завантаження експортує актуальну Drive-копію в локальний `.schdk`.
  На десктопі місце експорту вибирається через системний діалог збереження.

Якщо автозбереження не вдалося, редактор не змінює файл призначення. Потрібно
повторити збереження або знову підключити Google Диск. Під час закриття
десктопний застосунок очікує завершення збереження й у разі помилки пропонує
повторити спробу, закрити без збереження або скасувати закриття.
