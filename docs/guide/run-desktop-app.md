# Запуск повного десктопного застосунку

```powershell
pnpm dev:all-desktop
```

Команда збирає спільну вебоболонку з лінивими бандлами гри й редактора питань,
збирає головний процес Electron та запускає розгорнутий на весь екран
десктопний застосунок `SCHDK`. Це єдиний десктопний застосунок проєкту.

Десктопний редактор має доступ до справжніх шляхів файлової системи. Тому
недавній пакет відкриває поточний файл із диска, а не кешовану браузерну копію.
Після повторного запуску спільний застосунок відновлює останній активний розділ,
а редактор намагається знову відкрити попередній файл і вибране питання. Якщо
файл переміщено або видалено, застарілий стан очищується й редактор показує
помилку замість повторних невдалих спроб.
