# Запуск повного десктопного застосунку

```powershell
pnpm dev:desktop
```

Команда збирає спільну вебоболонку з лінивими бандлами гри й редактора питань,
збирає головний процес Electron та запускає розгорнутий на весь екран
десктопний застосунок `SCHDK`. Це єдиний десктопний застосунок проєкту.

Десктопний редактор працює з пакетами на Google Диску. Локальний `.schdk`
можна вибрати для імпорту, а запис у файлову систему відбувається лише під час
явного експорту через системний діалог збереження. Після повторного запуску
застосунок відновлює останній активний розділ, Drive-пакет і вибране питання,
якщо пакет доступний у поточному обліковому записі.
