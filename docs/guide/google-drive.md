# Підключення Google Диска

Google Диск зберігає створені та імпортовані пакети `.schdk`, автоматичні зміни
редактора й налаштування застосунку. Веб- і десктопний застосунки працюють із
тією самою актуальною копією пакета та потребують підключення до Google Диска.

Веб- і десктопний застосунки вже містять свої публічні OAuth client ID.
`VITE_GOOGLE_WEB_CLIENT_ID` і `GOOGLE_DESKTOP_CLIENT_ID` потрібні лише для
їхньої заміни під час розробки.

Вебзастосунок зберігає короткочасний access token у сховищі поточної вкладки.
Після завершення його дії застосунок просить підключитися знову. Десктопний
застосунок відкриває системний браузер і зберігає refresh token через захищене
сховище операційної системи.
