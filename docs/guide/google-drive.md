# Підключення Google Диска

Google Диск зберігає створені та імпортовані пакети `.schdk`, автоматичні зміни
редактора й налаштування застосунку. Веб- і десктопний застосунки працюють із
тією самою актуальною копією пакета та потребують підключення до Google Диска.

Веб- і десктопний застосунки вже містять свої публічні OAuth client ID.
`VITE_GOOGLE_WEB_CLIENT_ID`, `GOOGLE_DESKTOP_CLIENT_ID` і
`GOOGLE_DESKTOP_CLIENT_SECRET` потрібні лише для їхньої заміни під час
розробки. `GOOGLE_DESKTOP_CREDENTIALS_PATH` вказує на завантажений credentials
JSON під час пакування десктопного застосунку; файл не комітиться.

Для production OAuth використовується підтверджений домен `щдк.com.ua`:
домашня сторінка застосунку доступна за `/about.html`, а політика
конфіденційності — за `/privacy.html`. Власність домену в Google Search Console
має підтверджувати акаунт власника або редактора відповідного Google Cloud
проєкту.

Вебзастосунок тримає короткочасний access token лише в пам'яті поточної
сторінки. Після оновлення сторінки або завершення дії токена застосунок просить
підключитися знову. Десктопний застосунок відкриває системний браузер і зберігає
refresh token через захищене сховище операційної системи.
