# Запуск повного вебзастосунку

```powershell
pnpm dev
```

Відкрийте <http://127.0.0.1:5173>. Команда запускає один сервер розробки Vite;
Розділи «Провести гру» і «Редагувати пакети питань» завантажуються окремими
JavaScript-бандлами після першого відкриття:

| Адреса                  | Застосунок                  |
| ----------------------- | --------------------------- |
| <http://127.0.0.1:5173> | Об'єднаний застосунок SCHDK |

Порт фіксований. Якщо він зайнятий, команда завершиться з помилкою.

Після відкриття пакета браузер додає його ідентифікатор до параметра
`?package=`. Перезавантаження такого URL автоматично відкриває актуальний пакет
із Google Диска, якщо підключено той самий обліковий запис і файл ще доступний.
Посилання містить лише ідентифікатор Drive-файла й не надає доступу до
локальної файлової системи.
