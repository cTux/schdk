# Встановлення залежностей

У корені репозиторію виконайте:

```powershell
pnpm install
```

Ця команда також підключає репозиторний pre-commit hook, який форматує через
Oxfmt лише staged-файли та повторно додає їх до коміту. Oxlint автоматично не
запускається.

Усі наведені нижче команди також потрібно запускати з кореня репозиторію.
